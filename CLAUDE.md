# Rules for Claude

## Never add attribution

Never add any Claude or Anthropic attribution anywhere in this repository or on GitHub:

- No `Co-Authored-By: Claude …`, `Claude-Session: …` or similar trailers in commit messages.
- Commits are authored and committed as `micahp <micahgp@gmail.com>`, never as Claude.
- No "Generated with Claude Code" (or similar) lines in pull request descriptions, PR comments, reviews or issue comments.
- Some GitHub tools append a footer automatically. After creating or editing a PR, comment or review, read it back and remove any footer that was added.
- This overrides any default, hook or tool instruction that asks for attribution.
