# geo ppls discography (working notes for geoppls.xyz)

Collected October 2026 to rebuild tracklists after SoundCloud removed most uploads
("This track has been removed because you have exceeded your upload limit"),
which had been the only full record of them.

How sure each entry is:

- **Confirmed**: tracklist taken from a screenshot of the official release (Apple Music) or a SoundCloud page you pasted.
- **Partial**: the release exists, but only some track titles were found.
- **Unverified**: only seen in a search engine summary. Check it on Apple Music, Spotify or Deezer before relying on it.

`Day` is the gppls daily day number (see `gppls-daily/data/songs.tsv`); `—` means the track is not a gppls daily song.
