OVERVIEW

YapGPT is a ChatGPT-style chat app that anyone could use for free. It launched in May 2025 as Innovative Hype Chat at chat.innovativehype.xyz and was renamed YapGPT at yapgpt.xyz in June 2025.

It’s built on LibreChat, the open-source chat interface, customized to serve free models through OpenRouter, with document search powered by local Ollama models. Bring an OpenRouter key and the paid models unlock too.

FEATURES

  • Free models through OpenRouter, no API key required.
  • Document search: upload files and ask questions about them, using retrieval-augmented generation with local Ollama embeddings.
  • Local inference with Ollama for the parts that don’t need a frontier model.
  • Everything LibreChat ships: multiple model providers, agents and tools with MCP support, a code interpreter, artifacts and image generation.
  • Custom Innovative Hype branding, deployed with Docker Compose on my own server.

STATUS

YapGPT is offline for now. The code is on GitHub, and you can run your own copy with docker compose up.
